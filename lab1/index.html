1. История создания

JavaScript был создан в мае 1995 года программистом Бренданом Айком из компании Netscape Communications. По рассказам, первый прототип был написан всего за десять дней для браузера Netscape Navigator. Изначально язык назывался Mocha, затем LiveScript, а название JavaScript появилось в декабре 1995 года в рамках соглашения Netscape и Sun Microsystems.

Название было выбрано из маркетинговых соображений: тогда набирал популярность Java. Несмотря на схожее имя и часть синтаксиса, это два разных языка. В 1996 году Microsoft выпустила собственную реализацию — JScript, и возникла проблема несовместимости браузеров.

Чтобы решить эту проблему, язык стандартизировали: в 1997 году организация Ecma International приняла стандарт ECMAScript (ECMA-262). В 2005 году технология AJAX сделала возможными интерактивные веб-приложения, а в 2009 году Райан Даль выпустил платформу Node.js на движке V8, позволившую запускать JavaScript на сервере. Подробнее читайте в статье Википедии.

Любое приложение, которое может быть написано на JavaScript, в конечном итоге будет написано на JavaScript.
— закон Этвуда, 2007

Ключевые события

  1. 1995 — создание языка в Netscape.
  2. 1997 — первый стандарт ECMAScript.
  3. 2009 — появление Node.js и ECMAScript 5.
  4. 2015 — ECMAScript 2015 (ES6).

2. Краткий обзор языка

JavaScript — мультипарадигменный язык с динамической типизацией, прототипным наследованием и функциями первого класса. Код выполняется в одном потоке с использованием цикла событий (event loop), а современные движки (V8, SpiderMonkey) используют JIT-компиляцию. Спецификация и документация: MDN Web Docs. Пример кода см. в разделе «Примеры кода».

Основные особенности

  • Динамическая слабая типизация.
  • Прототипное наследование и синтаксис классов.
  • Асинхронность: промисы и async/await.

Области применения

  • Интерактивные веб-страницы (DOM, события).
  • Серверная разработка (Node.js).
  • Мобильные и десктопные приложения (React Native, Electron).
